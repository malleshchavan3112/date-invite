# Design System

## Direction
Premium + playful + romantic + minimal.

Avoid:
- Generic dating-app UI
- Excessive hearts everywhere
- Clutter
- Cheap gradients
- Overly childish graphics

## Colors
Background: #FFF8F5
Primary: #FF4F7B
Dark: #1F1F1F
Soft Pink: #FFE4EC
White: #FFFFFF
Muted: #777777

## Typography
Headings: DM Serif Display or Playfair Display
Body/UI: Inter

## Components
- Primary button
- Secondary button
- Choice card
- Text input
- Progress indicator
- Toast
- Modal
- Success card
- Error card

## Motion
- 180–350ms micro-interactions
- Smooth page transitions
- Gentle floating decorative elements
- Button press feedback
- Subtle celebration after successful submission

## Accessibility
- Keyboard accessible
- Visible focus states
- Adequate contrast
- Touch targets at least 44px
- Reduced-motion fallback
